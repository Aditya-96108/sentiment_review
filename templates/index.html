📘 About This Project

This application uses machine learning (Logistic Regression + TF-IDF) to classify IMDb movie reviews as positive or negative. Built with Flask and Bootstrap, it provides a clean and responsive interface for real-time analysis.

Made with ❤️ for movie lovers and data enthusiasts.
